# DSA03 NLP Assignment 3 – Helpdesk Parser

## Requirements
- Python 3.9 or later
- No external packages required

## Run
```bash
python main.py
```

The program contains a controlled helpdesk CFG, domain lexicon, a chart-based Earley recognizer, a bounded recursive-descent recognizer, 30 test cases, and an illustrative PCFG attachment calculation.

**Important:** This is a compact educational implementation. The handwritten derivations and PCFG probabilities in the report are worked examples; the implementation is a recognizer/ranking demonstration rather than a full feature-unification parser or a complete parse-tree enumerator.
