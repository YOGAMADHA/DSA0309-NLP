DSA0309 NLP Assignment-2 
================================
1. Run: python code/run_assignment.py
2. The script uses only Python standard-library modules and a fixed random seed (42).
3. It creates outputs/results.json and outputs/results.txt.
4. The corpus is SYNTHETIC and generated from transport-enquiry templates. It is a reproducible prototype, not real call-centre data.
5. The script demonstrates counting, n-gram counts, add-k perplexity and an HMM/Viterbi tagging prototype. It does NOT claim to complete the assignment's human annotation, independent agreement, 200 real ASR hypothesis sets, or full Katz/Good-Turing/Brill experiments. Those require actual corpus/annotators/recogniser data.
6. Run from the package root so the outputs folder is created in the expected location.
