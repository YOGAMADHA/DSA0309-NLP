# DSA03 NLP Assignment 4 – Semantic Systems Mini Demonstration

## Requirements
- Python 3.9 or later
- No external packages are required (Python standard library only)

## Run on Windows 11 / VS Code
1. Extract this ZIP file.
2. Open the `DSA03_NLP_Assignment4_GitHub_Project` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:
   ```bash
   python --version
   python main.py
   ```
5. The terminal prints demonstrations for all six Part II task areas.

## Project files
- `main.py` – event frames, a finite knowledge-base check, attachment alternatives,
  rule-based WSD, semantic retrieval ranking and an integrated crane/bank example.
- `screenshots/assignment4_output.png` – sample program output screenshot.
- `requirements.txt` – no third-party dependencies.



## Important academic note
This is an optional, transparent, rule-based demonstration. It is not a production NLP
system and does not train a model. Some assignment questions are analytical and are
answered in the accompanying Word report. Part I explicitly says source code is not
required; Part II permits a documented manual analysis or a Python/NLP implementation.
